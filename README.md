# Bónus Lodja - Compre e ganhe

## GitHub Pages

1. Envie **toda a pasta** (incluindo `css/` e `js/`) para o repositório.
2. Settings → Pages → Branch: `main` → folder: `/ (root)`.
3. Abra: `https://SEU_USER.github.io/NOME_DO_REPO/login.html`

### Se o site aparecer sem cores/estilo
- Confirme que a pasta `css` está no GitHub.
- Teste abrir: `https://SEU_USER.github.io/NOME_DO_REPO/css/style.css`
  - Se der 404, os ficheiros CSS não foram enviados.

### Estrutura necessária
```
/
  login.html
  dashboard.html
  roleta.html
  css/style.css
  css/roleta.css
  js/storage.js
  js/...
```
